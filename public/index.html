Platform capabilities

Everything starts with a solid backend.

A growing set of backend building blocks designed to help you move from idea to working product.

♙

Authentication

Create accounts, sign in securely and protect your project APIs with token-based authentication.

▤

Document database

Organize JSON documents into collections and manage your app data from the Webbase Console.

⌘

Developer console

Create and manage projects, inspect collections and work with your data in one responsive workspace.

⌁

REST API

Use straightforward HTTP endpoints to connect your own frontend, mobile app or server.

◈

Security foundations

JWT sessions, password hashing, security headers and request limits are part of the starter.

☁

Cloud services PLANNED

Storage, realtime events, hosting and serverless functions are planned platform modules—not live yet.
